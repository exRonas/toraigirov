# 📐 Структура энциклопедии Торайгырова

## Общая архитектура

```
ПУБЛИЧНЫЙ САЙТ (читатели)
├── Главная страница /
├── Поиск /search (FTS5 по всему контенту)
│
├── СТАТЬИ (7 разделов - через один механизм)
│   ├── /biography           → Биография
│   ├── /creativity          → Творчество
│   ├── /articles            → Статьи и публикации
│   ├── /readings            → Торайгыровские чтения
│   ├── /named-after         → Названы именем

│

│
└── Нижняя часть
    └── Ссылка на админ-панель (неприметная)


АДМИНИСТРАТОРСКАЯ ПАНЕЛЬ (с авторизацией)
└── /admin
    ├── /login              → Вход (Email + Password)
    │
    ├── /articles           → Управление статьями
    │   ├── Фильтр по разделам (7 вариантов)
    │   ├── Список с поиском
    │   ├── Редактирование
    │   └── Новая статья
    │
    ├── /poems              → Управление стихами
    │   ├── Список
    │   ├── Редактирование
    │   ├── Загрузка текста (KZ + RU)
    │   └── Загрузка аудио (MP3)
    │
    ├── /archive            → Управление архивом
    │   ├── Вводный текст (KZ + RU)
    │   ├── Фотоархив
    │   │   ├── Управление категориями
    │   │   ├── Загрузка фото (JPG, PNG, WEBP)

    │   ├── Фильтр по типам (книга, статья, диссертация, прочее)

    │   ├── Редактирование
```

## 🔄 Поток данных: Как контент попадает на сайт

### Путь для Статей (7 разделов)

```
Администратор
    ↓
/admin/articles → Выбирает раздел
    ↓
Нажимает "Новая статья"
    ↓
Заполняет: название, текст, обложка (KZ + RU)
    ↓
PostgreSQL Database (Article таблица)
    ↓
/biography, /creativity, /articles и т.д.
    ↓
Читатель видит список статей (отсортированы алфавитно)
    ↓
Клик на статью → Открывается полный текст с обложкой
```

### Путь для Стихов

```
Администратор
    ↓
/admin/poems → Нажимает "Новое стихотворение"
    ↓
Заполняет: название, текст KZ, текст RU, аудио (MP3, опционально)
    ↓
SQLite Database (Poem таблица)
    ↓
/poems
    ↓
Читатель видит список стихов (отсортированы по названию)
    ↓
Клик на стихо → Открывается текст + кнопка для прослушивания аудио
```

### Путь для Фото/Видео Архива

```
Администратор
    ↓
/admin/archive

    ФОТО:                          ВИДЕО:
    ├── Выбирает категорию         ├── YouTube:
    ├── Перетаскивает JPG/PNG         └── Вставляет URL
    ├── Названия (KZ+RU)           ├── MP4:
    └── Нажимает Сохранить            ├── Вводит название
                                       ├── Перетаскивает файл
                                       └── Обложка генерируется автоматически
    ↓
    /uploads/ (на диске)
    ↓
    SQLite Database (Photo, Video таблицы)
    ↓
    /archive (публичная страница)
    ↓
    Фото в masonry-галерее с лайтбоксом
    Видео в сетке (YouTube + MP4 с превью)
    ↓
    Клик на фото → Лайтбокс
    Клик на видео → Modal с плеером
```

### Путь для Библиографии

```
Администратор
    ↓
/admin/bibliography → Выбирает тип (книга, статья, диссертация)
    ↓
Заполняет: автор, название, год, издатель, примечания (KZ+RU)
    ↓
SQLite Database (BibliographyEntry таблица)
    ↓
/bibliography
    ↓
Читатель видит отфильтрованный список по типам
    ↓
Может скопировать информацию об источнике
```

## 🗄️ Таблицы базы данных

```sql
-- Статьи (7 разделов)
Article {
  id, sectionSlug (фильтр), title_kz, title_ru,
  content_kz, content_ru, coverImage, isDraft,
  publishedAt, createdAt, updatedAt
}

-- Стихи (с аудио)
Poem {
  id, title_kz, title_ru, text_kz, text_ru,
  yearWritten, audioFile, createdAt, updatedAt
}

-- Фото
Photo {
  id, filename, title_kz, title_ru, altText,
  category, sortOrder, createdAt
}

-- Видео
Video {
  id,
  youtubeUrl?, youtubeId?,  ← YouTube
  videoFile?, thumbnail?,   ← MP4 (обложка генерируется)
  title_kz, title_ru, category, createdAt
}

-- Категории для фото и видео
PhotoCategory {
  id, slug (уникальный), name_kz, name_ru
}

-- Библиография
BibliographyEntry {
  id, author, title_kz, title_ru, year,
  publisher, type (book|article|dissertation|other),
  notes_kz, notes_ru, createdAt
}

-- Страницы (вводные тексты для разделов)
Page {
  id, slug (уникальный для раздела), 
  title_kz, title_ru,
  content_kz, content_ru, updatedAt
}

-- Основные настройки
SiteSettings {
  id (singleton), heroQuote_kz, heroQuote_ru,
  quoteAuthor_kz, quoteAuthor_ru,
  siteTitle_kz, siteTitle_ru,
  footerText_kz, footerText_ru,
  linkVk, linkFacebook, linkTelegram, linkInstagram, linkYoutube,
  contactAddress, contactPhone, contactEmail,
  updatedAt
}
```

## 🎯 Ключевые особенности

| Функция | Реализация |
|---------|-----------|
| Двуязычность | KZ + RU для всего контента |
| Поиск | FTS5 (полнотекстовый поиск) |
| Сортировка | Алфавитная по текущему языку (localeCompare) |
| Фото | Masonry-галерея + лайтбокс |
| Видео YouTube | Встроенный плеер + автообложка |
| Видео MP4 | Загрузка + **автогенерация обложки в браузере** |
| Аудио | MP3 (для стихов) |
| Форматирование | Rich Text Editor (Tiptap) |
| Обложки | Загрузка + автогенерация (для MP4) |
| Медиа | Хранение в `/public/uploads/` + API `/api/file/` |
| Категории | Для фото и видео (customizable) |
