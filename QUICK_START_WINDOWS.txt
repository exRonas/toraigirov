📝 ШАГ 0: ТРЕБОВАНИЯ (выполни ДО развёртывания)

□ Администраторский доступ на Windows Server 2019
□ Доменное имя или публичный IP адрес
□ Интернет подключение на сервере

═══════════════════════════════════════════════════════════════════════════════

🚀 ШАГ 1: УСТАНОВКА ПО (30 минут)

A) Установи Node.js LTS:
   1. Скачай с https://nodejs.org/ (версия 20.x или 22.x)
   2. Запусти инсталлер от администратора
   3. Убедись что "Add to PATH" выбран
   4. Проверь: powershell → node --version

B) Установи NSSM:
   1. Скачай с https://nssm.cc/download
   2. Распакуй в C:\nssm\
   3. Добавь C:\nssm\win64 в PATH (System Properties)
   4. Проверь: powershell → nssm --version

C) Установи Nginx (если нет):
   1. Скачай с https://nginx.org/en/download.html
   2. Распакуй в C:\nginx\
   3. Проверь: powershell → cd C:\nginx && .\nginx.exe -t

═══════════════════════════════════════════════════════════════════════════════

📂 ШАГ 2: КОПИРОВАНИЕ ПРОЕКТА (5 минут)

1. Создай папку:
   mkdir C:\Apps\toraygyrov-encyclopedia

2. Скопируй весь проект туда:
   - ЛИБО через Git: git clone <URL> C:\Apps\toraygyrov-encyclopedia
   - ЛИБО вручную скопируй все файлы

═══════════════════════════════════════════════════════════════════════════════

⚙️ ШАГ 3: КОНФИГУРАЦИЯ (10 минут)

1. Создай .env файл:
   - Скопируй .env.windows-server.example как .env
   - Отредактируй:
     * NEXTAUTH_SECRET: сгенерируй 32+ символа
     * ADMIN_PASSWORD_HASH_B64: используй bcrypt хеш (см. инструкцию в файле)
     * NEXTAUTH_URL: укажи URL твоего сервера

2. Скрой .env файл:
   attrib +h C:\Apps\toraygyrov-encyclopedia\.env

═══════════════════════════════════════════════════════════════════════════════

🔨 ШАГ 4: СБОРКА (15 минут)

Запусти PowerShell от администратора и выполни:

  cd C:\Apps\toraygyrov-encyclopedia
  npm install
  npx prisma migrate deploy
  npm run build

═══════════════════════════════════════════════════════════════════════════════

🎯 ШАГ 5: АВТОМАТИЧЕСКОЕ РАЗВЁРТЫВАНИЕ (5 минут)

Отличный способ - используй готовый скрипт!

Запусти PowerShell от администратора:

  powershell -ExecutionPolicy Bypass -File C:\Apps\toraygyrov-encyclopedia\scripts\deploy-windows-server.ps1

Скрипт автоматически:
✓ Создаст Windows Service
✓ Включит логирование
✓ Откроет порты 80 и 443
✓ Запустит сервис

═══════════════════════════════════════════════════════════════════════════════

🌐 ШАГ 6: NGINX КОНФИГУРАЦИЯ (10 минут)

1. Скопируй конфиг:
   Copy-Item nginx\toraygyrov.conf C:\nginx\conf\sites-available\

2. Отредактируй:
   - Открой C:\nginx\conf\sites-available\toraygyrov.conf
   - Меняй "yourdomain.com" на свой домен/IP
   - Если используешь SSL - раскомментируй ssl строки

3. Подключи в основной конфиг:
   - Открой C:\nginx\conf\nginx.conf
   - Найди блок "http { ... }"
   - Добавь строку: include C:/nginx/conf/sites-available/*.conf;
   - Сохрани

4. Проверь синтаксис:
   C:\nginx\nginx.exe -t
   Должен вывести: "test is successful"

5. Перезагрузи:
   Restart-Service nginx

═══════════════════════════════════════════════════════════════════════════════

🔓 ШАГ 7: ОТКРЫТИЕ ДОСТУПА (5 минут)

Брандмауэр Windows уже открыт скриптом, но проверь:

  Get-NetFirewallRule -DisplayName "Allow HTTP"
  Get-NetFirewallRule -DisplayName "Allow HTTPS"

Если маршрутизатор за NAT, открой порты:
1. 192.168.1.1 (веб-интерфейс маршрутизатора)
2. Port Forwarding → 80→80, 443→443 → IP твоего сервера

Если домен - добавь A-запись на ip адрес сервера в регистраторе домена

═══════════════════════════════════════════════════════════════════════════════

✔️ ШАГ 8: ПРОВЕРКА (5 минут)

Проверь что всё работает:

1. На сервере в браузере:
   http://localhost
   http://localhost:3000

2. С другого компьютера:
   http://yourdomain.com
   http://server-ip

3. Вход в админку:
   /admin/login
   Email: admin@toraygyrov.kz
   Password: (тот что указал в .env)

4. Проверь логи:
   Get-Content "C:\Apps\toraygyrov-encyclopedia\logs\stdout.log" -Tail 50

🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

Ошибка "SERVICE_NOT_RUNNING":
  → Проверь логи: Get-Content "C:\Apps\...\logs\stderr.log"
  → Проверь .env файл
  → Проверь БД: npx prisma migrate deploy

Nginx не подключается к приложению:
  → Проверь статус: nssm status ToraygyrovEncyclopedia
  → Проверь порт: netstat -ano | findstr :3000
  → Проверь конфиг: C:\nginx\nginx.exe -t

Доступ из интернета не работает:
  → Проверь брандмауэр: Get-NetFirewallRule | findstr "Allow HTTP"
  → Проверь маршрутизатор (Port Forwarding)
  → Проверь DNS: nslookup yourdomain.com
